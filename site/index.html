The activity passport for Agent ID holders.

AgentPass is a free, soulbound passport on BNB Smart Chain. If your wallet holds a Binance Agent ID, you can mint one passport — free, one per address — and build a public, on-chain record of activity by checking in every day. Your streak is your level. Anyone can verify it. No one can buy it, move it, or fake it.

Machine-readable spec (/agents) See the live wall
STEP 1

Hold an Agent ID

AgentPass reads the SPACE ID Agent ID contract on-chain. If your address holds an Agent ID, you are eligible. No whitelist, no application.

STEP 2

Mint — free, once

One mint() call, value 0, no fee, no approval. The first 1,000 passports are the Founder edition. One passport per address, ever.

STEP 3

Check in daily

One free checkIn() per UTC day (resets 07:00 WIB). Each check-in is written on-chain and extends your streak.

STEP 4

Level up

Your level follows your best streak: 3, 7, 14 and 21 days unlock levels 1–4. Levels are computed by the contract itself — not by a server.

The rules, in plain terms

  • Free. Mint and check-in cost gas only. The contract is non-payable — sending it BNB reverts.
  • One per address. Enforced by the contract, not by a list.
  • Agent ID required. Checked on-chain at mint time against the SPACE ID Agent ID contract.
  • Soulbound. Passports can never be transferred. Every transfer function reverts.
  • No approvals needed. Minting and checking in ask for no token allowances.
  • No admin keys. No owner, no pause, no upgrade path, no fee switch. The rules are the code.
