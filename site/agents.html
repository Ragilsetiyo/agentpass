--------------------------------------------------------------------------------
RULES
--------------------------------------------------------------------------------
- One passport per address. Enforced on-chain (passportOf).
- Agent ID required at mint time (see eligibility gate above).
- Soulbound: transferFrom and both safeTransferFrom variants always revert
  with "AgentPass: soulbound". Approvals can be recorded but are inert.
- Level = f(best streak): level 1 at 3 days, 2 at 7, 3 at 14, 4 at 21.
  Level never decreases; it follows the BEST streak, not the current one.
- Check-in day boundary is UTC (unix day = timestamp / 86400; resets 07:00 WIB).
- The contract holds no funds and has NO admin functions: no owner, no pause,
  no price setter, no withdraw, no upgrade path. Owner permissions: none.
- Metadata attributes are fully reproducible on-chain via attributesOf();
  the metadata server is a renderer, not a source of truth.
- AgentPass promises no returns, rewards, or future value. It is an activity
  record, not a financial product.

VERIFICATION API + AGENTSCORE (for projects that want to check a holder)
--------------------------------------------------------------------------------
verify_endpoint:    GET https://agentpass-sigma.vercel.app/api/verify?address=0x...
                    GET https://agentpass-sigma.vercel.app/api/verify?tokenId=184
returns (JSON):     address, tokenId, holdsPassport, founder, edition, level,
                    levelLabel, streak, bestStreak, totalCheckIns, agentScore,
                    scoreBreakdown, scoreFormula, scoreName, scoreVersion,
                    blockNumber
eligibility:        GET https://agentpass-sigma.vercel.app/api/eligibility?address=0x...&minLevel=1
                    GET .../api/eligibility?address=0x...&minScore=25 (or both)
                    At least one of minLevel (0..4) / minScore (0..100) is
                    required. Returns: address, eligible (bool), requirements,
                    actual {holdsPassport, founder, tokenId, level, agentScore},
                    scoreName, scoreVersion, blockNumber. No passport:
                    HTTP 200 with eligible=false. Bad parameter: 400.
no_passport:        HTTP 200 with holdsPassport=false and agentScore=0 (not an
                    error). tokenId not minted: 404. Bad parameter: 400.
                    All RPC down: 502.
caching:            responses may be cached 60s (browser) / 300s (edge). For
                    block-fresh data inside a contract, call passportOf /
                    attributesOf on-chain directly (selectors above).
agent_score:        "AgentScore — Participation & Consistency Score", version 1.
                    0..100, computed ONLY from attributesOf fields:
                      score = round( 60 * min(bestStreak, 21) / 21
                                   + 40 * min(checkIns, 30) / 30 )
                    Holding a passport, Founder edition and level earn NO
                    points: founder is an edition badge, and level is derived
                    from best streak, so it is never counted twice.
                    No passport = 0. Fixed public formula, frozen at v1 —
                    recomputable from raw contract reads; the API is a
                    convenience, not a source of truth. Full docs:
                    /developers on this site.
use_as_gate:        example — require holdsPassport=true and level >= 1 for an
                    airdrop/mint aimed at active Agent ID holders, or call
                    /api/eligibility and read the eligible flag directly.
