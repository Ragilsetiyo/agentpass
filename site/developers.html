Verification API & AgentScore

AgentPass passports are public, soulbound and fully on-chain — so any project can verify them. This API lets your app, airdrop, mint or agent check, in one call: does this address hold an AgentPass, at what level, and what is its AgentScore? Free, read-only, no API key, no signup.

Endpoint

CallWhat it answers
GET /api/verify?address=0x… Passport status, edition, level, streaks, check-ins and AgentScore for a wallet address.
GET /api/verify?tokenId=184 The same, starting from a passport number instead of an address.
GET /api/eligibility?address=0x…&minLevel=1&minScore=25 A yes/no gate: does this address's passport meet your bar? At least one of minLevel (0–4) or minScore (0–100) is required; both may be given. Try it live in the gate playground below.
GET /api/token/<id> ERC-721 metadata for a passport (the endpoint the contract's tokenURI points at).

Base URL: https://agentpass-sigma.vercel.app. Every answer is read live from the AgentPass contract on BNB Smart Chain (passportOf + attributesOf) via public BSC RPC. Responses may be cached up to 60 seconds by browsers and 300 seconds at the edge, so a cached answer can lag the chain by a few minutes. If you need block-fresh data inside a smart contract, call the contract views directly — see “On-chain alternative” below.

A non-holder is a normal 200 answer with holdsPassport: false and score 0 — not an error. Errors: 400 for a missing or malformed parameter, 404 for a tokenId that has not been minted, 502 when every public RPC is unreachable.

AgentScore v1 — the formula

AgentScore — Participation & Consistency Score (version 1) is a 0–100 score computed only from two fields of attributesOf(uint256). The formula is fixed, public and frozen — anyone can recompute the exact same score from raw contract reads:

score = round( 60 × min(bestStreak, 21) / 21  +  40 × min(checkIns, 30) / 30 )
ComponentPointsSource field
Best streak (consistency)60 × streak / 21, max 60 at a 21-day best streakbestStreak
Lifetime check-ins (participation)40 × check-ins / 30, max 40 at 30 check-inscheckIns
Totalmax 100No passport = 0

Holding a passport, the Founder edition and level earn no points. Founder is an edition badge (returned as its own field), and level is derived from best streak by the contract itself — awarding points for level as well would count the same streak twice.

Correction, published openly (23 Nov 2026): the first draft of this formula, live for a few hours on launch day — before any external project had integrated the API — awarded 10 points for holding a passport, 10 for Founder and 10 per level on top of per-day points, double-counting level. It was replaced the same day by the v1 formula above, which is the frozen one. Every API response carries scoreName and scoreVersion so consumers can pin the version they rely on.

AgentScore measures recorded on-chain participation and consistency only. It is not a trust or reputation rating, not a financial rating, not a credit score, and it promises nothing.

Eligibility endpoint — the yes/no gate

If you only need a decision, skip the arithmetic: /api/eligibility compares a passport against your bar and returns a single eligible flag. Set minLevel (0–4), minScore (0–100), or both — at least one is required.

curl "https://agentpass-sigma.vercel.app/api/eligibility?address=0xe242f296…&minLevel=1"
→ { "eligible": true, "requirements": { "minLevel": 1, "minScore": null },
    "actual": { "holdsPassport": true, "founder": true, "tokenId": 10,
                "level": 1, "agentScore": 13 }, "scoreVersion": 1 }

curl "https://agentpass-sigma.vercel.app/api/eligibility?address=0x21351a1Aa7f55596883Bd7861D9A92Dc59f2d0D6&minScore=25"
→ { "eligible": false, "requirements": { "minLevel": null, "minScore": 25 },
    "actual": { "holdsPassport": true, "founder": true, "tokenId": 184,
                "level": 0, "agentScore": 4 }, "scoreVersion": 1 }

An address with no passport is a normal 200 answer with eligible: false — not an error. Errors: 400 for a missing address, a malformed value, or no requirement at all; 502 when every public RPC is unreachable. Responses also carry a blockNumber.

Use it as a gate

Example: an airdrop or mint page that requires an AgentPass at level 1 or higher (best streak of 3+ days). The shortest path is the eligibility endpoint:

const r = await fetch(
  'https://agentpass-sigma.vercel.app/api/eligibility?address=' +
  userAddress + '&minLevel=1'
);
const v = await r.json();
if (v.eligible) {
  // eligible — a real, active Agent ID holder
} else {
  // not eligible yet — point them to mint + check in
}

Or read the raw facts from /api/verify and decide yourself:

const r = await fetch(
  'https://agentpass-sigma.vercel.app/api/verify?address=' + userAddress
);
const v = await r.json();
if (v.holdsPassport && v.level >= 1) { /* eligible */ }

On-chain alternative: if your gate lives inside a smart contract, skip the API and read the AgentPass contract directly — passportOf(address) (selector 0x5d1c2634) returns the tokenId (0 = none), and attributesOf(uint256) (selector 0x09363c44) returns owner, founder, streak, best streak, check-ins and level in one call. Full signatures and selectors: /agents.
