Verification API & AgentScore

AgentPass passports are public, soulbound and fully on-chain — so any project can verify them. This API lets your app, airdrop, mint or agent check, in one call: does this address hold an AgentPass, at what level, and what is its AgentScore? Free, read-only, no API key, no signup.

Endpoint

CallWhat it answers
GET /api/verify?address=0x… Passport status, edition, level, streaks, check-ins and AgentScore for a wallet address.
GET /api/verify?tokenId=184 The same, starting from a passport number instead of an address.
GET /api/token/<id> ERC-721 metadata for a passport (the endpoint the contract's tokenURI points at).

Base URL: https://agentpass-sigma.vercel.app. Every answer is read live from the AgentPass contract on BNB Smart Chain (passportOf + attributesOf) via public BSC RPC. Responses may be cached up to 60 seconds by browsers and 300 seconds at the edge, so a cached answer can lag the chain by a few minutes. If you need block-fresh data inside a smart contract, call the contract views directly — see “On-chain alternative” below.

curl "https://agentpass-sigma.vercel.app/api/verify?address=0x8330249bB1249Ab31f803194F3BA4A28722bb3ee"
→ { "holdsPassport": false, "tokenId": null, "agentScore": 0,
    "scoreBreakdown": { "passport": 0, "founder": 0, "level": 0, "checkIns": 0, "bestStreak": 0 } }

A non-holder is a normal 200 answer with holdsPassport: false and score 0 — not an error. Errors: 400 for a missing or malformed parameter, 404 for a tokenId that has not been minted, 502 when every public RPC is unreachable.

AgentScore — the formula

AgentScore is a 0–100 activity score computed only from the fields of attributesOf(uint256). The formula is fixed and public — anyone can recompute the exact same score from raw contract reads:

ComponentPointsSource field
Holds a passport10passportOf(address) != 0
Founder edition10founder
Level10 per level (max 40)level (0–4)
Lifetime check-ins1 each (max 20)checkIns
Best streak1 per day (max 20)bestStreak
Totalmax 100No passport = 0

AgentScore measures recorded on-chain activity only. It is not a financial rating, not a credit score, and it promises nothing.

Use it as a gate

Example: an airdrop or mint page that requires an AgentPass at level 1 or higher (best streak of 3+ days):

const r = await fetch(
  'https://agentpass-sigma.vercel.app/api/verify?address=' + userAddress
);
const v = await r.json();
if (v.holdsPassport && v.level >= 1) {
  // eligible — a real, active Agent ID holder
} else {
  // not eligible yet — point them to mint + check in
}

On-chain alternative: if your gate lives inside a smart contract, skip the API and read the AgentPass contract directly — passportOf(address) (selector 0x5d1c2634) returns the tokenId (0 = none), and attributesOf(uint256) (selector 0x09363c44) returns owner, founder, streak, best streak, check-ins and level in one call. Full signatures and selectors: /agents.
